JavaScript Data Types

This project demonstrates all the **data types in JavaScript** — both **primitive** and **non-primitive (reference)** types — with simple examples.

---

## 📘 Overview

JavaScript has two main categories of data types:

1. **Primitive Data Types**
   - Number  
   - String  
   - Boolean  
   - Undefined  
   - Null  
   - Symbol  
   - BigInt  

2. **Non-Primitive (Reference) Data Types**
   - Object  
   - Array  
   - Function
